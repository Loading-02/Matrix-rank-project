    Null space (changes the queries cannot detect)

      Notes for the report and viva

      • Rank = number of independent queries. A query that adds nothing to the earlier ones is redundant.
      • rank + nullity = number of records. A nonzero nullity means the data cannot be recovered uniquely.
      • Stability: try the near-dependent example. Change the tolerance from 1e-9 to 1e-13 and the computed rank changes, because a tiny pivot is either noise or real depending on the tolerance.
      • This tool uses Gaussian elimination with partial pivoting. For serious work, SVD-based rank is more reliable.
